# Student Notes Portal

A lightweight, responsive web portal for university students to access organized notes and lecture slides across branches and semesters.

## Planned Features
- Student entry point with year, branch, and semester selection
- Quick materials download links (notes & slides)
- Admin portal for course and curriculum management
- 100% offline-first architecture with vendored assets
